
# Part 2 — Data Curation Plan

## Overview

This module implements the BUSA3022 Part 2 proof of concept for Really Big Bank.

It builds on the curated ASX 200 and VIX datasets generated by Part 1. The objective is to calculate market metrics, align Australian and US market observations, validate data quality, and prepare an analytics-ready dataset for Part 3.

## Input Data

- `data/curated/asx200_curated.csv`
- `data/curated/vix_curated.csv`

## Calculated Metrics

### 1. 20-Day Moving Average
The arithmetic mean of the latest 20 ASX trading-session closing prices.

Purpose: Identify the underlying market trend by smoothing short-term price fluctuations.

### 2. Daily Return (%)
Formula: ((Current Close / Previous Close) - 1) * 100

Purpose: Measure daily market performance and enable comparisons over time.

### 3. 14-Day Rolling Volatility
The sample standard deviation of the latest 14 daily percentage returns.

Purpose: Measure recent market variability. The result is not annualised.

## ASX–VIX Date Alignment

The proof of concept uses pandas.merge_asof() with:

- direction="backward"
- allow_exact_matches=False

Each ASX observation is paired with the latest VIX observation dated strictly before its ASX trading date.

This is a conservative date-based approximation designed to avoid forward-looking same-calendar-date matches.

Production deployment requires verification of actual source publication timestamps, timezone conversion, daylight-saving changes, and observation freshness.

## Data Quality

The implementation checks:

1. All ASX observations are preserved.
2. ASX closing prices are positive and non-missing.
3. ASX trading dates are unique.
4. Matched VIX dates precede ASX trading dates.
5. Matched VIX observations contain valid, non-missing values.

The initial dataset contains 131 ASX observations, of which 129 receive VIX matches.

Two unmatched ASX records (9–10 April 2026) retain missing VIX values rather than being deleted.

Two source ASX volume observations were flagged as unavailable in Part 1. Price-based metrics remain calculable for these records.

Initial moving-average and volatility values are left missing until sufficient historical observations exist.

## How to Run

Run all commands from the repository root.

Install dependencies:

    python3 -m pip install -r requirements.txt
    python3 -m pip install matplotlib

Calculate ASX metrics:

    python3 curation/calculate_metrics.py

Generate the aligned dataset:

    python3 curation/align_market_data.py

Create the portfolio figure:

    python3 curation/plot_part2_chart.py

## Outputs

- `data/curated/market_aligned.csv` — Combined ASX/VIX observations and calculated metrics.
- `assets/part2_market_chart.png` — Market trend and VIX context portfolio figure.

## Implementation Notes

This is an educational proof of concept, not a production market-data system.

The code preserves source datasets and generates separate analytical outputs. Changes to metric definitions, date-matching rules, or data-quality checks should be reviewed and tested before merging into the main repository.
